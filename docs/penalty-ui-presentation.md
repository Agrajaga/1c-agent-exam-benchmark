# Структурированное представление штрафов

Состояние: реализация и проверка завершены 26 октября 2026 года.
Ветка `codex/penalty-codes`, база `upstream/main`:
`ce301ce8ff6f23b0c1bb5c571f56190157e8f7ac`.

## Согласованный объём

Изменяется только представление штрафов после экзамена и в рейтинге:
название, объяснение результата проверки, основание, исходная диагностика.
Существующее сообщение сохраняется целиком в раскрываемом блоке.
Начисление, исходные оценки, схема и содержимое пакета результата для PR
не изменяются.

## Реализация и решения

- `site/penalty-cards.js` — общий рендерер и объяснения известных форматов.
  Неизвестные коды/форматы сохраняют исходную диагностику и не получают
  придуманных числовых результатов или причин. Для PR13 таблица содержит
  только суммы, явно присутствующие в сообщении проверки.
- Названия и номера правил/требований берутся из отдельного файла интерфейса
  `penalty-info.json`, формируемого из существующей «Методики». В него входят
  только title/number, без тестовых оракулов и служебных данных. Неоднозначные
  ID разных билетов не получают потенциально неверную подпись.
- `measure.js` и `leaderboard.js` используют один рендерер. Локально основания
  ведут к конкретной карточке «Методики»; публичный сайт показывает их текстом,
  поскольку страницы «Методика» там нет.
- Повторный опрос неизменившегося результата сохраняет раскрытые блоки.
  Все строки выводятся через textContent; диагностический текст не исполняется
  как HTML. Повторные места обнаружения сгруппированы для чтения, исходная
  строка с повторами сохранена.
- Сборщики сайта добавляют только файлы представления; импорт общего модуля
  получает версию по содержимому. public_evaluation, prepare_bundle, make_pr,
  оценщик и community/results не изменены.

## Проверка

- Новые проверки сначала упали из-за отсутствия представления; после
  реализации прошли. Отдельно воспроизведены и исправлены обработка кириллицы
  в имени ресурса и пояснение обычных признаков учёта; оба случая покрыты
  регрессиями. Признаки учёта субконто остаются отдельным случаем BU07.
- Полный Python-набор: 286 тестов, OK, 21 пропущен (265 успешных).
  Включает запуск восьми JavaScript-проверок через Node.js.
- Собраны локальный каталог и публичный сайт. В обоих экспортируемый result
  семи опубликованных сдач совпал с оригинальным evaluation.json; внутри
  каждого архива evaluation.json, assessment.json и manifest.json совпали
  с оригиналами побайтно. Эта граница дополнительно покрыта тестом.
- В браузере просмотрены итог сохранённого экзамена и публичный рейтинг.
  Проверены раскрытие полного сообщения, сохранность раскрытия после
  автообновления, переход к Т3.13/BU13 и отсутствие неработающих ссылок на
  «Методику» в публичном рейтинге.
- Независимое ревью после исправлений: существенных замечаний не осталось.
  `git diff --check` пройден.

Работающий пользовательский стенд не обновлялся: браузерная проверка шла
через отдельный предпросмотр, допускающий только GET к его данным. Экзамены,
переоценки и публикации из предпросмотра не запускались.
