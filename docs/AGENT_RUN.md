# Задание агенту: воспроизводимый замер и PR

Прочитай [инструкцию участника](COMMUNITY.md). Работай из клона репозитория.
Цель: подготовить локальный стенд, выполнить один замер Codex, независимо оценить
зафиксированную сдачу и подготовить PR с результатом.

1. Проверь Python 3.11+, Git, установленную 1С, Codex CLI и вход в него.
   Не скачивай и не публикуй лицензию 1С, ключи или `auth.json`.
2. Создай `.venv`, выполни `python -m pip install -e .`, запусти
   `python tools/start_demo.py`. На Windows используй Python из `.venv/Scripts`,
   на Linux/macOS из `.venv/bin`. Каркас уже в
   `starters/carcass-8.3.25.1445/new_carcass_8_3_25_1445.dt`.
3. Автор берётся из `gh auth login` оператора, платформа и Codex находятся автоматически.
   Уточни у оператора лимит решения. Не выдумывай автора, характеристики оборудования или результаты.
4. На странице «Замер» пройди проверку готовности, включая проверку грейдера. Не обходи
   её и не меняй эталоны для её прохождения.
5. Выбери готовое окружение. Если запрошена Unica 0.14 RC1, используй именно её;
   другую версию или отсутствие харнеса не выдавай за этот замер. Харнес готовится кнопкой
   «Подготовить» в шаге «Харнесы» или командой `python tools/prepare_native_harnesses.py --install --check <id>`.
6. Запусти одну попытку. Зафиксируй её ID. Не подсказывай решающему агенту закрытые
   тесты и не редактируй его файлы. При ошибке инфраструктуры сохрани ошибку;
   не представляй её как провал решения. Перезапуск — новая попытка.
7. Дождись автоматической независимой оценки. Никогда не представляй собственные
   тесты решающего агента как результат грейдера. Не заменяй верхнюю границу точным баллом.
8. Подготовь пакет кнопкой или `python -m tools.community_results prepare ID`.
   Обязательны `solution.dt`, полный `src/`, binding, оценка, автор, параметры среды,
   run и manifest. DT строится из замороженного XML в свежей базе.
   Не исправляй сдачу задним числом ради её загрузки; если загрузка не проходит,
   сообщи об этом, не удаляй DT из требований.
9. Проверь содержимое пакета, затем при наличии поручения отправить результат
   используй кнопку PR или `python -m tools.community_results pr ID`.
   Требуется `gh auth login`. Инструмент работает через отдельный checkout форка,
   копирует только пакет в `community/results/ID` и создаёт PR в основную репу.
   Не меняй видимость репозитория и не коммить весь рабочий каталог.
10. Сообщи ID замера, модель, харнес, версию 1С, время, оценку с её ограничениями
    и ссылку на PR. Если PR не создан, честно укажи причину и путь к подготовленному пакету.

Для независимого пересчёта: настрой и откалибруй свою платформу, затем выполни
`python -m tools.recheck_community ID --output .local/rechecks/НОВЫЙ_ID`.
Исходный пакет не менять. Новую оценку сохранять отдельно вместе с отпечатком грейдера.
