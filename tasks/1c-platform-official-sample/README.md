# Официальный открытый пример платформенного экзамена

## Происхождение

Условие и методика взяты из официального документа 1С
[ATT83PL.rtf](https://static.1c.ru/rus/partners/training/files/ATT83PL.rtf) со
[страницы примеров билетов](https://1c.ru/spec/questions.htm), скачан 9 октября 2026 года
(2 202 485 байт, SHA-256 `9cfbc21905fd378274f2d8e0f8a428ac0c83733c8f0a48e08d1fc4c7215fcc61`).
Оригинал в Git не хранится; его хеш и хеши всех полученных файлов закреплены в
[манифесте](manifest.json).

- **Условие** — пример билета (строки 279–486 текстового вида) выделен в
  [statement.docx](public/statement.docx), [statement.txt](public/statement.txt) и
  [рисунки](public/assets/) с сохранением таблиц; четыре страницы сверены визуально.
- **Методика** — строки 1–278 до заголовка «Примеры заданий:» без пересказа выделены в
  `public/methodical-requirements.txt`, включая все 75 позиций списка ошибок и штрафов.
- **Правила стенда** — отличия от методики 1С (максимум диапазона штрафа, суммирование
  разных штрафов за один дефект, границы оценок и др.) вынесены отдельно в
  `public/assessment-policy.md`; официальный текст не меняется.
- **Каркас** — официальный `new_carcass_8_3_25_1445.dt` из той же страницы лежит в
  `starters/carcass-8.3.25.1445/` с квитанцией загрузки и закреплённым хешем.

Официальный реализованный пример (`primer_iz_sbornika.dt`) агенту не выдаётся.

## Что получает агент

Весь `public/`: условие, методику, правила стенда, `protocol.md` (протокол сдачи) и
`binding-contract.json` (какие объекты и поля решения назвать проверяющему).
Конкретные сценарии, входные данные, ожидаемые результаты и проверяющий код агенту
не выдаются.

## Для куратора

- [Приёмка](acceptance.md): правила, сценарии и открытые вопросы.
- [Штрафы 1С и правила стенда](official-assessment-mapping.md), [решения владельца](owner-scoring-policy.md).
- [Исследование решений](reference-research.md): официальный кандидат, обсуждение, видео.
- `private/`: машинные правила, данные сценариев, карта происхождения
  (`methodical-source-map.json`, `source-map.json`).

Воспроизведение и проверка из корня проекта (только стандартная библиотека Python):

```sh
python3 tools/verify_task_package.py          # хеши и происхождение пакета
python3 tools/prepare_open_exam_requirements.py  # пересобрать методику и правила стенда
```

`tools/prepare_official_statement.py` повторяет выделение условия из локально
конвертированного оригинала и сбрасывает отметку визуальной проверки.
