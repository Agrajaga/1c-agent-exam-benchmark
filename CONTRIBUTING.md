# Участие в замерах

Начните с [инструкции участника](docs/COMMUNITY.md). Для агента есть
[отдельное поручение](docs/AGENT_RUN.md).

В PR с результатом должен быть один новый каталог `community/results/ID/`.
Используйте кнопку подготовки пакета: обязательны полный XML/BSL, DT решения,
параметры среды и компьютера, автор, условия запуска, оценка и manifest SHA-256.
Не отправляйте `.local/`, лицензию 1С, ключи, `auth.json` и сырые журналы.

CI проверяет целостность и комплектность. После слияния заявленная оценка появится
на GitHub Pages. Проверка CI не является независимым подтверждением балла.
Если меняете грейдер или хотите пересчитать результат, сохраняйте новую оценку
отдельно от оригинального пакета. Не заменяйте старые DT/XML улучшенным решением.
