Замер

Стенд сам проверит компьютер, поможет поставить недостающее, даст агенту решить билет и оценит решение в настоящей 1С. Результат можно отправить в общий рейтинг.

Стенд не запущен

Эта страница работает только из клона репозитория на вашем компьютере.

git clone https://github.com/zeegin/1c-agent-exam-benchmark.git
cd 1c-agent-exam-benchmark
python -m venv .venv
.venv/bin/python -m pip install -e .        # Windows: .venv\Scripts\python
.venv/bin/python tools/start_demo.py
